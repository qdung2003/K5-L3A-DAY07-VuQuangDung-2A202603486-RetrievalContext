# Earlier demonstration

The original project contained a synthetic 32-chunk Vietnamese policy dataset, a
hash-token vector representation and a heuristic controller. Their data and code
are retained in `data/legacy/`, `src/legacy/` and `docs/legacy/heuristic-report.md`
for reference. Existing `starter/results/` artifacts refer to that demonstration.

They are not the final Day 7 benchmark, neural embedding, agent evaluation or report.
Final evidence is stored in the tracked `results/` directory and uses the actual
licensed Day 6 Python Tutorial snapshot. `src/make_reviews.py` is the old draft-label
utility and must not be used to grade the final neural pipeline.
