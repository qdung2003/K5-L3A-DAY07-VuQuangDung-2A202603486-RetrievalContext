# Execution notes

The final runs use the real Day 6 Python 3.13.15 virtual environment for
Chroma 1.5.9, Sentence Transformers 6.3.0, Transformers 5.22.2 and PyTorch 2.15.0.
The installed OpenAI 3.46.0 SDK and its missing dependencies were made available
from the host Python site-packages via an appended import path. This changes no
sibling project files. A fresh installation uses `requirements.txt` instead.

Before final dev evaluation, the first five configuration attempts failed with
an HTTP 400 SDK serialization error (`async_` rather than the API alias `async`).
They are retained in each dev folder's `errors.json`. Serialization now uses
aliases and excludes nulls. The successful runs are separate; no error was replaced
with a mock answer. Preliminary connection probes and failed requests are not
included in the successful agent-token totals, so those totals are not a complete
account invoice. There was also an initial runtime missing-SDK error before model
execution; no answers were generated by that attempt.

The user explicitly allowed sending public Python Tutorial excerpts and study
questions to the configured OpenAI endpoint, with possible API charges. An earlier
automatic approval review blocked the benchmark until this confirmation arrived.
No credential values are stored in traces or reports.

Before test, a duplicate test topic was replaced with import search order and the
amendment was recorded in `data/benchmark_freeze.json`; the original freeze is
retained. Citation extraction was corrected to count inline citations in abstention
answers. Original answer text and provider output were retained; the exact list
corrections are in `pretest_corrections.json`. These corrections happened before
selection and before any final test query was run.

Agent labels were produced by an AI judge and then directly inspected by Codex.
For baseline Q11, Codex lowered the answer grade from 2 to 1 because the cited
namespace passage did not establish the requested variable assignment. The original
judge decision and the correction are retained in `codex-dev-review.json`.
This is AI-assisted source inspection, not the student's personal or independent
human review. The author-review CSV is intentionally unfilled.

After the initial benchmark, the project gained central `.env` configuration,
independent `--results-root` folders, generic named-reviewer imports, and dated
public-price cost estimation. These changes do not rewrite frozen model outputs,
dev summaries or selection hashes. The original `runtime.json` describes the
benchmark code/environment at execution time; current validation is recorded
separately so historical code hashes are not misrepresented as the new version.
